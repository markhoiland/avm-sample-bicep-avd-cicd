# Module: session-hosts

Deploys **Azure Virtual Desktop session host VMs** via the [AVM module `avm/res/compute/virtual-machine`](https://github.com/Azure/bicep-registry-modules/tree/main/avm/res/compute/virtual-machine) and registers them with a Host Pool using the AVD DSC extension. Optionally joins VMs to **Microsoft Entra ID** (Azure AD Join) instead of a traditional domain.

---

## Usage from `main.bicep`

The orchestration file (`bicep/main.bicep`) deploys this module conditionally at resource-group scope:

```bicep
module sessionHosts './modules/session-hosts/main.bicep' = if (deploySessionHosts) {
  name: 'sessionHosts-${uniqueString(deployment().name)}'
  scope: resourceGroup(rg.name)
  params: {
    location: resourceGroupLocation
    hostPoolName: hostPool.outputs.name
    hostPoolRegistrationToken: hostPool.outputs.registrationToken   // @secure()
    subnetResourceId: !empty(sessionHostSubnetResourceId)
      ? sessionHostSubnetResourceId
      : (vnet.?outputs.avdshSubnetResourceId ?? '')
    sessionHostCount: sessionHostCount
    sessionHostNamePrefix: sessionHostNamePrefix
    vmSize: sessionHostVmSize
    adminUsername: sessionHostAdminUsername
    adminPassword: sessionHostAdminPassword                         // @secure(), from GitHub secret
    enableEntraIdJoin: enableSessionHostEntraIdJoin
    entraIdLoginRoleAssignments: sessionHostEntraIdLoginRoleAssignments
    availabilityZone: sessionHostAvailabilityZone
    imageSku: sessionHostImageSku
    osDiskType: sessionHostOsDiskType
    tags: union(globalTags, sessionHostTags)
  }
}
```

Set `deploySessionHosts = true` in your parameter file to enable this module. A non-empty `sessionHostAdminPassword` must be provided (via the `SESSION_HOST_ADMIN_PASSWORD` GitHub secret) or the Bicep assertion will fail the deployment.

## Parameters

| Name | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| `location` | `string` | | Resource group location | Azure region where VMs will be deployed. |
| `hostPoolName` | `string` | ✅ | — | Name of the existing Host Pool to register session hosts with. |
| `hostPoolRegistrationToken` | `string` *(secure)* | ✅ | — | Host Pool registration token. Generated by the host-pool module when `registrationInfo` is supplied. |
| `subnetResourceId` | `string` | ✅ | — | Subnet resource ID for the VM network interfaces. Supply either `sessionHostSubnetResourceId` or enable `deployVirtualNetwork`. |
| `sessionHostCount` | `int` | | `2` | Number of VMs to deploy (min 1, max 100). |
| `sessionHostNamePrefix` | `string` | | `'vm-avd-sh'` | Naming prefix. VMs are named `{prefix}-001`, `{prefix}-002`, etc. |
| `vmSize` | `string` | | `'Standard_D4s_v3'` | Azure VM size. |
| `adminUsername` | `string` | ✅ | — | Local administrator username for the VMs. |
| `adminPassword` | `string` *(secure)* | ✅ | — | Local administrator password. Never commit to source; supply via the `SESSION_HOST_ADMIN_PASSWORD` GitHub secret. |
| `enableEntraIdJoin` | `bool` | | `false` | Join VMs to Microsoft Entra ID (AAD Join) instead of a traditional domain. |
| `entraIdLoginRoleAssignments` | `array` | | `[]` | Role assignments (e.g. `Virtual Machine User Login`) applied at resource-group scope for Entra ID login. Only active when `enableEntraIdJoin` is `true`. |
| `availabilityZone` | `int` | | `0` | Pin VMs to an availability zone (`1`–`3`). `0` = regional (no zone pinning). |
| `imageSku` | `string` | | `'win11-22h2-avd'` | Windows marketplace image SKU. See `az vm image list --publisher MicrosoftWindowsDesktop --offer Windows-11 --all` for available SKUs. |
| `osDiskType` | `string` | | `'Premium_LRS'` | Managed disk type: `Premium_LRS`, `StandardSSD_LRS`, or `Standard_LRS`. |
| `tags` | `object` | | `{}` | Tags applied to all VMs and NICs. |

### `entraIdLoginRoleAssignments` array — element shape

```bicep
{
  roleDefinitionIdOrName: 'Virtual Machine User Login'  // well-known name, GUID, or full ARM ID
  principalId: '<object-id>'                            // Entra ID user, group, or SP object ID
  principalType: 'Group'                                // User | Group | ServicePrincipal | Device (optional but recommended)
}
```

| Friendly name | GUID |
|--------------|------|
| `Virtual Machine User Login` | `fb879df8-f326-4884-b1cf-06f3ad86be52` |
| `Virtual Machine Administrator Login` | `1c0163c0-47e6-4577-8991-ea5c82e286e4` |

## How session hosts are registered

1. The **host-pool module** generates a short-lived registration token (valid 2 hours) when `registrationInfo` is supplied.
2. The **AVD DSC extension** (`Microsoft.Compute/virtualMachines/extensions`) is installed on each VM. It downloads the AVD Configuration DSC package, runs `AddSessionHost`, and registers the VM using the token passed as a protected (secure) extension setting.
3. When `enableEntraIdJoin = true`, a **system-assigned managed identity** is attached to the VM and the `AADLoginForWindows` extension runs first to complete the Entra ID join before host pool registration.

## Outputs

| Name | Type | Description |
|------|------|-------------|
| `sessionHostResourceIds` | `array` | ARM resource IDs of all deployed session host VMs. |
| `sessionHostNames` | `array` | Names of all deployed session host VMs. |

## Example: standalone deployment

```bicep
module sessionHosts './modules/session-hosts/main.bicep' = {
  name: 'sessionHosts'
  params: {
    location: 'eastus'
    hostPoolName: 'vdpool-avd-prod-001'
    hostPoolRegistrationToken: '<token>'   // @secure()
    subnetResourceId: '/subscriptions/<sub>/resourceGroups/rg-avd-prod-001/providers/Microsoft.Network/virtualNetworks/vnet-avd-prod-001/subnets/snet-avdsh'
    sessionHostCount: 2
    sessionHostNamePrefix: 'vm-avd-sh'
    vmSize: 'Standard_D4s_v3'
    adminUsername: 'avdadmin'
    adminPassword: '<secret>'             // @secure()
    enableEntraIdJoin: true
    entraIdLoginRoleAssignments: [
      {
        roleDefinitionIdOrName: 'Virtual Machine User Login'
        principalId: '<avd-users-group-object-id>'
        principalType: 'Group'
      }
    ]
    imageSku: 'win11-22h2-avd'
    osDiskType: 'Premium_LRS'
    tags: {
      Environment: 'Production'
      Workload: 'AVD'
    }
  }
}
```
